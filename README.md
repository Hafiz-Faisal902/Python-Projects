# Python Projects

A hands-on Python learning repository built one project at a time.

The goal is to move from small beginner programs to larger software, automation, and AI-focused systems while keeping each step understandable and useful.

## How it works

Projects are grouped by difficulty. Each project can be run on its own, and the root `main.py` provides a central launcher for the projects that have been added to it.

```text
Python-Projects/
├── main.py
├── programs/
│   ├── 01_beginner/
│   ├── 02_beginner-intermediate/
│   ├── 03_intermediate/
│   ├── 04_advanced/
│   ├── 05_ai-automation/
│   └── 06_professional/
├── docs/
├── .gitignore
├── .gitattributes
└── LICENSE
```

## Running a project

Run a project directly, for example:

```bash
python programs/01_beginner/To_Do_List/main.py
```

Or start the central launcher:

```bash
python main.py
```

The launcher lets you move between available projects without restarting the program.

## Learning approach

This repository follows a simple progression:

**Build → understand → test → improve → repeat**

Early projects stay intentionally simple. As the projects become more serious, the repository will gradually introduce better structure, testing, validation, configuration, documentation, APIs, databases, automation, and other engineering practices.
